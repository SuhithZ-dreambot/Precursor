How to read this prototype. Traffic is synthetic — generated to mimic CICIDS2017-style attack signatures (port-scan/DDoS, credential stuffing, exfiltration), each with a recon "buildup" phase before onset, since this sandbox can't reach the academic hosts for the real CICIDS2017 / CSE-CIC-IDS2018 / ToN_IoT datasets. The pipeline itself is real: generate_data.py → feature_engineering.py (rolling stats + EWMA/CUSUM drift) → pipeline.py (XGBoost forecaster trained on a time-ordered 70/30 split, fused with the statistical signal, thresholded, lead time measured against true onset). Swap in real flow data by replacing generate_data.py's output — the schema is unchanged. Metrics above are illustrative of the method on this synthetic set, not a production accuracy claim.
